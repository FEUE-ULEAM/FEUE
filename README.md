# FEUE
Pagina Oficial de la FEUE ULEAM, espacio colaborativo entre miembros de la directiva estudiantil universitaria, pagina sin fines de lucro, unicamente para compartir información relevante, optimizar eventos, crear oportunidades y proyectar un mejor futuro.

Todos los derechos reservados, iniciativa Coordinador General de la FEUE ULEAM 2026.

Este repositorio es publico y toda la información confidencial es almacenada de forma local, bajo ninguna circunstancia se debe exponer datos ni informacion personal de la comunidad universitaria.
